# Sudokuverkstan

A sudoku game that runs entirely in the browser — one HTML file, no install.

**Play:** https://isac076.github.io/sudokuverkstan/ (once GitHub Pages is turned on)

## Features

- **Classic** sudoku in four difficulties: Easy, Medium, Hard, Expert
- **Killer** sudoku with cage sums
- **Variants** — mix your own rules: anti-knight, anti-king, non-consecutive, diagonal, hyper, disjoint groups, thermometers, Kropki dots, XV, even/odd, plus the original *Knight's ten* rule
- **Famous** puzzles, including the Miracle Sudoku and AI Escargot
- Every generated puzzle has exactly one solution
- Notes, auto-notes, hints, undo, check and a timer
- English and Swedish
- Progress is saved in the browser

## Keyboard

| Key | Action |
| --- | --- |
| 1–9 | Write a digit |
| Shift + digit | Toggle a note |
| N | Notes mode |
| Arrow keys | Move |
| Backspace | Erase |
| Ctrl + Z | Undo |

## Run locally

Download `index.html` and open it in any modern browser.
